# 🎓 Student Tracker

A responsive frontend project built using React and Vite for managing student details.

## 📌 Project Overview

Student Tracker is a simple student management system designed for:

* Staff
* Students
* Parents

The project includes login pages and student detail management features.

---

# ✨ Features

## 👨‍🏫 Staff Module

Staff can:

* Add student details
* View student details
* Edit student details
* Delete student details

### Staff Login

* ID: `staff`
* Password: `1234`

---

## 👨‍🎓 Student Module

Students can:

* Login using ID and password
* View their details

---

## 👨‍👩‍👧 Parent Module

Parents can:

* Login using student ID and password
* View student details

---

# 📝 Student Details Included

Each student record contains:

* Name
* Student ID
* Password
* Department
* Behaviour
* Arrears
* Fees Status
* Exam Fees Status

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/student-tracker.git
```

## Open Project

```bash
cd student-tracker
```

## Install Dependencies

```bash
npm install
```

## Run Project

```bash
npm run dev
```
